# Космический Телеграм

Проект представляет собой набор скриптов, которые автоматически скачивают космические фотографии NASA (`nasa_fetcher.py`, `nasa_epic.py`), SpaceX (`spacex_fetcher.py`) и публикуют их в телеграм‑канале с заданным интервалом (по умолчанию: каждые 4 часа, непрерывный цикл). Скрипт бота телеграмм для публикации (`cosmo_bot.py`) получает изображения из локальной папки `images`, которая создается при запуске скриптов для скачивания фото. Скрипт `helpers.py` вспомогательный.

Опубликовать можно любое фото из папки `images`. Пример запроса для публикации выбранного фото:
```
python cosmo_bot.py images\nasa_apod_1.jpg
```
### Как установить

#### 1. Клонируйте или скачайте проект

#### 2. Установите зависимости

Python3 должен быть уже установлен. 
Затем используйте `pip` (или `pip3`, есть есть конфликт с Python2) для установки зависимостей:
```
pip install -r requirements.txt
```
Рекомендуется использовать [модуль venv](https://docs.python.org/3/library/venv.html) для изоляции проекта.

##### 3. Создайте и заполните файл с ключами

Для получения данных от API NASA потребуется сервисный ключ – “токен”. Зарегистрируйтесь на [сайте NASA](https://api.nasa.gov/#apod), на указанную при регистрации почту вам будет отправлен сервисный ключ на подобии такого: 
```
82a02da882a02da882a02da8a981b7f3cc882a082a02da8e4af9c41e8551329276dde72. 
```
Для публикации в Telegram нужно предварительно создать бота и получить его API-токен (через бота `BotFather`)

Создайте `.env` файл в корне проекта. В нём должны быть:
```
NASA_API_TOKEN=ваш_токен_от_API_NASA
COSMO_TG_TOKEN=ваш_токен_бота_из_BotFather
CHANNEL_ID=@ваш_канал
```

Python3 должен быть уже установлен. 
Затем используйте `pip` (или `pip3`, есть конфликт с Python2) для установки зависимостей:
```
pip install -r requirements.txt
```
Рекомендуется использовать [модуль venv](https://docs.python.org/3/library/venv.html) для изоляции проекта.
